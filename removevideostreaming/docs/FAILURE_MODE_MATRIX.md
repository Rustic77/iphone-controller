# Failure mode matrix

Derived from `RemotePhone.Agent.Core.Reliability.FailureModeCatalog`.

| Trigger | Expected behavior | Automatic protection | Recovery procedure | Pass condition |
|---------|-------------------|----------------------|--------------------|----------------|
| AirPlay receiver window closed or process exited | Capture transitions Capturing → SourceLost; streaming pauses cleanly | SourceLost signaling message; frame queue cleared; no stale frames pushed | Re-detect receiver window; transition SourceLost → Capturing on restore | Stream resumes within reconnect budget without agent restart |
| AirPlay source resolution or orientation change mid-session | VideoMetadata republished; orientation helper updates Portrait/Landscape | Drop in-flight frames with mismatched dimensions; recalibrate pointer scales | Invalidate pointer calibration; send updated VideoMetadata; resume capture | Client receives new metadata and taps map correctly after recalibration |
| Capture FPS collapse / producer overrun | BoundedFrameQueue drops oldest frames; DroppedFrames increments | Queue capacity default 3 prevents unbounded memory growth | Lower PreferredFps/bitrate; monitor SoakMetrics.DroppedFrames | Memory stable under soak; dropped frames reported; stream remains connected |
| Capture pipeline error (GraphicsCapture failure) | State machine Capturing → Error; Error signaling message emitted | Stop push-frame path; dispose capture resources | Error → Idle\|Selecting; operator reselects source; restart capture | Agent returns to Idle/Selecting and can start a new session |
| WebRTC peer connection ICE failure | ConnectionState → Failed or Reconnecting; ReconnectAsync invoked | ExponentialBackoff between reconnect attempts; SessionGate rejects stale offers | ReconnectAsync with fresh offer/answer; reuse session only if gate accepts | Media path restored or clean Failed state with Error message to client |
| WebRTC media path stalls (zero FPS while Connected) | NotifyFrame stats show StreamFps collapse; health watchdogs fire | Heartbeat continues; optional soft reconnect without tearing down capture | ReconnectAsync; if still stalled, StreamStop then StreamStart | StreamFps recovers above threshold within soak window |
| Signaling WebSocket disconnect | ISignalingClient.IsConnected false; reconnect with backoff | ExponentialBackoff; AgentRegister re-auth; reject messages until authenticated | ConnectAsync; AgentRegister; resume Heartbeat; renegotiate WebRTC if needed | Signaling restored; HeartbeatAck received; stream session continuity preserved or clean restart |
| Stale session messages after StreamStop / new StreamStart | SessionGate.Accept returns false for old sessionId | Ignore WebrtcOffer/Answer/IceCandidate for non-current session | SetSession on StreamStart; Clear on StreamStop | No cross-session ICE/SDP applied; only current session media established |
| Agent authentication failure | AgentAuthenticated Success=false; streaming never starts | Do not open capture or WebRTC until authenticated | Refresh AgentCredential; reconnect and re-register | Unauthenticated agent never pushes frames or accepts StreamStart |
| TURN/STUN unreachable / restrictive NAT | Connection may stay Connecting then Failed; ICE candidates exhaust | Configured TurnServers fallback; timeout to Failed | Verify StunServers/TurnServers in Agent options; retry ReconnectAsync | With valid TURN, Connected achieved; without, clear Failed + Error to client |
| Pointer calibration invalidated by orientation change | CalibrationState → INVALID; taps withheld or remapped after recalibration | Invalidate() bumps Version; HomingPlan re-establishes origin | BeginCalibrate; HomingPlan sweeps; MarkReady; apply ScaleX/ScaleY | NormalizedToEstimatedPixel within tolerance after READY |
| Long soak memory / reconnect pressure | SoakMetrics tracks Runtime, DroppedFrames, ReconnectCount, MemoryBytes | Bounded queue; backoff caps reconnect storms | Alert on ErrorCount/MemoryBytes thresholds; recycle agent process if needed | Multi-hour soak meets PassCondition thresholds without unbounded growth |

Use this matrix when designing Phase 5 automated/manual drills. Keep control-path HID failures in the ESP / controllerplatform docs — they are not video-path failures.
